# Katalog Wireframe Ultra Low-Fidelity (Balsamiq / Sketch Style)

Direktori ini berisi koleksi berkas visual **Wireframe Ultra Low-Fidelity** bergaya sketsa konseptual (*Balsamiq / Paper-Sketch Style*) untuk proyek redesain portal resmi Dinas Pemadam Kebakaran dan Penyelamatan Kota Bandar Lampung.

Gaya visual ini meniru persis kaidah rancangan kasar (*rough sketch wireframing*) pada interaksi manusia dan komputer (HCI):
1. **Palet Warna Monokromatik Murni**: Latar putih (`#FFFFFF`), bingkai dan garis hitam tegas 2px (`#222222`), blok panel abu-abu (`#EAEAEA`), dan batang placeholder teks abu-abu (`#777777`).
2. **Window Chrome Retro "Browser"**: Bilah judul bertuliskan *"Browser"* di tengah dengan tombol tutup `[X]`, tombol navigasi `[← →]`, tombol muat ulang `[↻]`, dan bilah alamat URL.
3. **Image Placeholder dengan Garis Silang Diagonal ("X")**: Kotak gambar dengan dua garis menyilang dari sudut ke sudut serta label penjelas di tengah kotak.
4. **Batang Placeholder Teks (*Text Placeholder Bars*)**: Garis horizontal tebal abu-abu pengganti salinan teks (*dummy copy*) agar evaluasi berfokus murni pada tata ruang, hierarki informasi, dan alur interaksi pengguna (*user task flow*), bukan pada teks akhir.

## 2. Relevansi dalam Tahapan Metodologi HCI (ISO 9241-210)

Dalam tahapan perancangan *User-Centered Design* (UCD), purwarupa berfidelitas rendah (*low-fidelity wireframe*) berfungsi sebagai:
1. **Eksplorasi Konseptual Cepat**: Menguji alokasi ruang (*spatial proportion*), tata letak modul, dan jalur pandang mata (*visual scanning path*) tanpa terdistraksi oleh warna, foto riil, atau tipografi rumit.
2. **Validasi Alur Tugas (*Task Scenario Flow*)**: Memastikan pengguna darurat dapat mengenali tombol panggil 113 dan direktori posko siaga dalam hitungan detik (*recognition efficiency*).
3. **Penyelarasan Tim Desain & Pengembang**: Menjadi cetak biru dasar sebelum melangkah ke purwarupa menengah (*mid-fidelity mockup*) dan purwarupa interaktif (*high-fidelity prototype* di Figma / Next.js).
