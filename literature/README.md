# Literature Corpus Directory

Direktori ini digunakan untuk menyimpan bahan literatur riset:
- `pdfs/`: Letakkan berkas PDF jurnal/prosiding di sini.
- `markdowns/`: Berkas Markdown hasil konversi dari PDF via `scripts/convert_pdf_to_md.py`.
- `references.bib`: Berkas master sitasi BibTeX terpadu.
