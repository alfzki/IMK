# ISO2019HumanCentred

ISO 9241-210:2019 Ergonomics of Human-System Interaction — Part 210: Human-Centred Design for Interactive Systems
International Organization for Standardization (2019)
Geneva: ISO.

Four Core Human-Centred Design (HCD / UCD) Activities:
1. Understand and specify the context of use: identifying users, tasks, environments, and emergency conditions.
2. Specify the user requirements: identifying functional, informational, and emotional user needs, constraints, and usability benchmarks.
3. Produce design solutions: creating information architectures, wireframes, visual design systems, and interactive prototypes.
4. Evaluate design solutions against user requirements: conducting heuristic evaluation, usability testing, and standardized instrument assessments (such as WebQual 4.0).

The cycle is inherently iterative until the usability goals are achieved.
