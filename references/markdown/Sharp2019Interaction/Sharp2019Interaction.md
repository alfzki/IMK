# Sharp2019Interaction

Interaction Design: Beyond Human-Computer Interaction (5th Edition)
Helen Sharp, Yvonne Rogers, and Jenny Preece (2019)
John Wiley & Sons, Indianapolis.

Core Interaction Design Principles:
1. User-Centered Approach: Involving users throughout design, understanding user tasks, goals, and operational context.
2. Usability Goals: Effectiveness, efficiency, safety, utility, learnability, and memorability.
3. User Experience (UX) Goals: Satisfying, helpful, engaging, trustworthy, emotionally supportive.
4. Iterative Prototyping: Progression from sketches and wireframes to interactive high-fidelity prototypes in tools like Figma.
5. Formative Evaluation: Usability testing and heuristic evaluations throughout development.
