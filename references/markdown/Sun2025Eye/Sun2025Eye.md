# Sun2025Eye

Eye Movements and User Emotional Experience: A Study in Interface Design
Na Sun and Yong Jiang (2025)
Frontiers in Psychology, 16, 1455177. https://doi.org/10.3389/fpsyg.2025.1455177

Abstract:
Interface design profoundly impacts users' emotional state, visual attention, and cognitive workload. Using eye-tracking methodologies and subjective affective ratings, this study investigated how visual clutter, visual hierarchy, and color palettes influence fixation duration, saccade amplitude, and emotional valence. The findings demonstrate that cluttered interfaces with dense bureaucratic text induce significant visual fatigue, elevated cognitive load, and negative emotional valence. Conversely, clean minimalist interfaces with structured visual hierarchies, distinct call-to-action buttons, and harmonious emotional color palettes significantly reduce visual friction and accelerate task completion speed.
